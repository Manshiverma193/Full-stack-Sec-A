# CampusConnect

CampusConnect is a full-stack campus management platform.

## Features

- Student registration and login
- JWT authentication
- Student/Admin role-based access
- Campus events
- Event registration
- Learning resources
- Admin dashboard
- Event management
- Resource management
- MongoDB database
- REST API

## Technologies

### Frontend

- React
- Vite
- Axios
- React Router

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## Run Project

### Backend

cd server

npm install

npm run dev

### Frontend

cd client

npm install

npm run dev

Frontend:

http://localhost:5173

Backend:

http://localhost:5000
