# CampusConnect

CampusConnect is a role-based college event and announcement portal.

## Technologies

- React
- Redux Toolkit
- Node.js
- Express
- MongoDB
- Redis
- Socket.io
- JWT
- bcrypt
- Docker
- Jest
- Supertest

## Roles

### ADMIN

- Create events
- Update events
- Delete events
- Create announcements

### STUDENT

- View events
- RSVP
- Receive live notifications

## Run Backend

cd backend

npm install

npm start

## Run Frontend

cd frontend

npm install

npm run dev

## Docker

docker compose up --build
